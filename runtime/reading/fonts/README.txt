Vendored 2026-10-04 as the full, unsubsetted TTF files (owner decision: no subsetting), so the original family
names are intact inside the files. They are served by the reading server at /fonts/<name> without a token, with
the licence texts beside them. To switch to woff2 later, change the four names and types in the server's ASSETS
table and the @font-face rules in style.css.
