# Public-content portability patch

The public tree uses repository-relative evidence paths, synthetic dialogue fixtures
and a self-contained microcopy scope exclusion. Public repository URLs, source
citations and generic operating-system examples remain intentional.

The original path check recognized only one Windows separator spelling. Its
replacement first failed on twelve archived research files: ten JSON records and
two working-directory notes. Regression cases cover raw Windows, slash-normalized,
JSON-escaped, macOS, Linux and mounted Windows home paths. The repository scan
covers documentation, skills, craft, source, launchers, runtime, evaluations and
fixtures. This is a check for those path forms, not a general privacy classifier.

All ten JSON records were compared before and after normalization: only the `path`
field changed. Research drafts, numerical diagnostics, review outcomes and source
attribution are preserved. Archive notes disclose normalized paths and anonymized
external skill handles; historical character counts retain their pre-redaction
meaning. Older public design examples and copied game fixtures were generalized.
Synthetic fixture round trips still preserve unrelated source bytes and restore
the entire original file on undo.

A fresh same-turn Yoda pair checked three routing prompts. Both the names-only
baseline and the current-metadata arm selected no listed skill for button/toast
microcopy, `prose-instruct` for a router-reset procedure and `prose-teach` for a
ninth-grade textbook lesson. The metadata arm found no required external installed
plugin. This small selection probe does not establish actual host activation,
writing benefit or a reliability rate.

The patch changes the current published tree and attached evaluation archive.
Previously published commits and source tags are historical and are not rewritten.

Verification on the patch: 138 test files passed, with 2,783 tests passed and two
existing skips. Typechecking and generated-reference/guide checks passed. After
the final documentation and source-comment edits, the portability/skill/guide
subset passed all 114 tests. An isolated managed 0.10.1 installation parsed,
measured and linted the textbook example, resolved its guide and included all
four teaching/reader resources. Its source fingerprint was
`8c86723b623afa2bf2aeec0e8d8fad8de508c45df82da1a091d0922d0875e086`.
Independent review also inspected all 23 tracked reading-page screenshots.
