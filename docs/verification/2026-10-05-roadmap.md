# Roadmap release verification

Scope: implement the craft-guide findings, render/export milestone and dialogue testbed tooling.
Linux CLI skill evaluations in CI remain excluded by the owner's decision. The game content pilot
still needs actual owner choices; verification uses copied fixtures and records synthetic test choices.

Final local gate: all 132 test files passed, with 2,584 tests passed and two skipped. Typecheck,
generated reference checks and the managed 0.7.0 installation with paired PDF browser passed.
The final journal-ignore addition passed its eight project-path tests separately.

The accepted design is [the roadmap implementation design](../superpowers/specs/2026-10-04-roadmap-render-dialog-fixes-design.md).

- Craft regressions cover first-scene page counting, hour-long/malformed timestamps, default sonnet
  and limerick meter counts, page-derived timing bands, hymn aliases, declared textual meter and family rhyme.
  Shared references are generated from the common registry; unsupported attribution and numerical claims were corrected.
- Async responsiveness checks use explicit lock/load holds and verify another operation completes
  before the hold releases, rather than comparing machine-speed thresholds.
- [Render verification](2026-10-05-render.md) records real paired-Chromium prints and visual inspection.
  Unit tests use a local fake audio provider; no paid OpenAI request was made.
- Dialogue regressions bind a selected source slot to its manifest, prediction and recorded pick;
  they reject protected edits, stale source, changed winners, duplicate slots and slot overflow.
  Apply/undo preserve exact source bytes outside the selected literal. Journal tests cover interrupted
  single- and multi-file writes, recovery and refusal to overwrite unrelated edits. Source locking is
  shared across canonical path spellings.
- An isolated copy of Space2grow's source and test dependencies was exercised with one bridge and
  one ambient fixture edit. Its existing bridge-dialog, ambient-lines and dialog-contract tests passed
  after apply (48 tests), and undo restored both original snapshots exactly. The live game was unchanged.

Independent code review found whole-topic reply counting, declared path budgets, canonical source
locking and arrival-line extraction gaps; these were addressed before release. The plugin's bounded
source adapter checks are supplemented by the game's own contract validators, which remain the
shipping gate for real game changes.
