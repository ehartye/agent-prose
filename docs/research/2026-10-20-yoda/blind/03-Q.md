# How to reset ResetLab

ResetLab is an invented classroom simulator, not real hardware. Saving works only while the status is **Ready**.

**Warning: A reset erases all unsaved changes.** Save before every reset.

1. While the status is **Ready**, select **Save copy**.
2. Confirm that **Copy saved** appears before you continue.
3. Hold **Reset** for exactly 4 seconds.
4. Release **Reset**.
5. Check the status for up to 20 seconds after release. Follow the path that matches:

- If **Ready** returns within 20 seconds, select **Open copy** to restore your saved copy.
- If **Busy** remains after 20 seconds, do not hold **Reset** again. Select **Help** and report the displayed session code. Never include a password in the report.
