# ResetLab: Save and Reset

ResetLab is an invented classroom simulator, not real hardware.

**Warning: A reset erases all unsaved changes.**

1. Check the status. You can save only while it says **Ready**. Before any reset, select **Save copy** and wait for **Copy saved**. Do not reset until you see that message.
2. Hold **Reset** for exactly **4 seconds**, then release it.
3. Use the matching path:
   - If **Ready** returns within **20 seconds**, select **Open copy** to restore your saved copy.
   - If **Busy** remains after **20 seconds**, do not hold **Reset** again. Select **Help** and report the displayed session code. **Never include a password in the report.**
