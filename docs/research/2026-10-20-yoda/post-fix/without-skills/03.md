# ResetLab reset steps

ResetLab is an invented classroom simulator, not real hardware.

**Warning: A reset erases all unsaved changes.**

1. When the status is **Ready**, select **Save copy**. Saving works only while **Ready** is shown. Check that **Copy saved** appears before any reset.
2. Hold **Reset** for exactly **4 seconds**, then release it.
3. Follow the matching path:
   - If **Ready** returns within **20 seconds**, select **Open copy** to restore your saved copy.
   - If **Busy** remains after **20 seconds**, do not hold **Reset** again. Select **Help** and report the session code shown on the screen. **Never include a password in the report.**
