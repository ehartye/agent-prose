# Screen and stage in Fountain

## Fountain essentials (Fountain 1.1)

| Element | Write it as |
|---|---|
| Title page | `Key: value` lines at the top, then a blank line. Keys: Title, Credit, Author, Source, Draft date, Contact, plus `Form` and `Target` for prose. |
| Scene heading | `INT. ROOM - NIGHT` on its own line with blank lines around it; force any line with a leading `.` |
| Action | Plain paragraphs. Force with `!` (needed when ALL-CAPS action sits right above dialogue). |
| Character cue | An ALL-CAPS name, blank line before, dialogue right after. Force with `@`. Extensions: `(V.O.)`, `(O.S.)`, `(CONT'D)`. Dual dialogue: `^` after the second cue. |
| Parenthetical | `(beat)` on its own line inside dialogue. |
| Transition | ALL-CAPS line ending `TO:` with blank lines around; force with `>`. |
| Centered | `>COLD OPEN<` — use this for act markers. |
| Sections / synopses | `#` and `=` lines are outline only and **do not print**. |
| Notes | Between `[[` and `]]`; a truly empty line ends a note. |
| Boneyard | Between `/*` and `*/`; ignored. |
| Page break | `===` |

## Multi-camera sitcom

- Description and action in ALL CAPS; dialogue double-spaced in the printed script; scenes
  lettered (`SCENE A`, `SCENE B`) with the scene's characters listed under the heading;
  entrances and exits underlined in print.
- Length: observed scripts run about 40–58 pages for a ~22-minute episode, so a page is roughly
  0.4–0.5 minutes. A cold open is typically 2–5 pages; each new scene starts a new page.
- Jokes per page are expected to be high and hard ("buttons" at scene ends), but every joke still
  comes from the premise.

## Single-camera comedy and hour drama

- Standard screenplay layout; about one page per minute (±20%).
- Single-cam comedy: about 22–35 pages, often a cold open plus three acts of 6–12 pages.
- Network hour drama: a teaser plus four to six acts; early acts run longer than late ones and
  each act ends on a turn. Streaming and cable scripts often omit act markers — match the show.

## Stage play

- Manuscript conventions: 12-point Courier, a character breakdown page (name, age, a line of
  description) before the script, act and scene citations, page numbers.
- The tool uses a provisional one-minute-per-page placeholder based on approximate screenplay
  layout; stage-play timing needs a measured rehearsal.

## Structure is guidance, not a rule

Three-act, four-part and beat-sheet models disagree with each other and with the data; use them
to diagnose a sagging middle, not as a template. Conflict-free structures (kishōtenketsu) are
legitimate when the brief calls for them.
